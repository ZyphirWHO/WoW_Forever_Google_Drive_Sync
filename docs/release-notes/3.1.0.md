## What's new in 3.1

- **Activity.** See what synced and when, in plain words: "Downloaded Details, WeakAuras and Key bindings from
  LAPTOP". Click an entry to see every file it changed.
- **Snapshots.** Save your setup under a name ("Before the raid UI rework") and put it back any time. Snapshots are
  kept until you delete them and don't count towards the 5 automatic backups.
- **Game updates.** When World of Warcraft is updated, a copy of your settings is saved first, so a patch that resets
  them can be undone in a click. The last 3 are kept.
- **Your computers.** Every computer that syncs, with when it last synced.
- **Pause for a while:** for 1 hour, 4 hours, until tomorrow morning, or until you resume.
- **Settings in one place,** with tabs: General, Sync, Cloud, Backups, Updates and Advanced.
- **Notifications your way:** all, only when something needs you, or none.
- **Save a backup as a zip** to keep it somewhere else.
- **Help and feedback:** Help, What's new, and Report a problem (opens a GitHub issue with the diagnostics filled
  in, folder names only, for you to check before sending).
- **The tray icon moves while syncing,** and its tooltip says when your settings last synced.
- **Uninstalling** can also remove your backups and settings if you want (the cloud folder is never touched).
- **Start with Windows stays on.** If its entry goes missing (for example after reinstalling), it is put back the
  next time Interface Sync opens; if Windows' own Startup apps list has it switched off, Settings says so. The first
  time it starts at sign-in it tells you it's running in the tray (Windows hides new tray icons behind the ^ arrow).
- Better keyboard and screen-reader support, and sharper at 150% and 200% display scaling.

### New to Interface Sync?

Interface Sync keeps your World of Warcraft interface settings (keybindings, macros and addon settings) the same on
every computer you play on, through your own Google Drive, OneDrive, Dropbox or iCloud Drive. Settings sync only
while the game is closed, every change is backed up first, and your game files, addons and `Config.wtf` are never
touched.

### Installing

- **Windows:** download `InterfaceSync-Setup-3.1.0.exe` and run it. It installs for you only, with no administrator
  rights needed. Windows may warn that it doesn't recognise the app yet: click **More info**, then **Run anyway**.
- **Mac:** download the `.dmg` for your Mac (`arm64` for Apple silicon, `x64` for Intel) and drag Interface Sync onto
  Applications. The first time you open it, go to System Settings → Privacy & Security and click **Open Anyway**.

Already using 3.0? It updates itself; your settings and backups are kept.
