Opening Interface Sync on a Mac

Interface Sync isn't from the App Store and isn't notarised by Apple yet, so the first time you open it macOS blocks it. You only have to do this once.

1. Put the app in Applications

  1. Drag Interface Sync.app into your Applications folder.
  2. Double-click it there.

2. macOS says it "can't be opened" — allow it (macOS 15 Sequoia and newer)

  1. In the warning, click Done (not "Move to Trash").
  2. Open System Settings (Apple menu → System Settings).
  3. Click Privacy & Security in the sidebar.
  4. Scroll down to the Security section. You'll see "Interface Sync" was blocked to protect your Mac.
  5. Click Open Anyway, then enter your Mac password (or use Touch ID).
  6. In the next box, click Open Anyway again.
The Open Anyway button only appears for about an hour after the blocked attempt. If it's gone, double-click the app again, then go back to Privacy & Security.

On macOS 14 Sonoma or older

  1. In Finder, Control-click (or right-click) Interface Sync in Applications and choose Open.
  2. Click Open in the box that appears.

3. Allow access to your cloud folder

The first time Interface Sync reads your Google Drive, OneDrive, Dropbox or iCloud Drive folder, macOS asks whether it may access files in that app. Click Allow. If you clicked "Don't Allow" by mistake: System Settings → Privacy & Security → Files and Folders → Interface Sync, and turn the folder back on.

4. First setup

A setup window explains how syncing works. If your cloud folder already has settings from another computer, it asks, for each game version, whether to use the settings already in the cloud or use this Mac's settings. The newer one is picked for you; the other copy is backed up either way. Click Start syncing.

Leave Open Interface Sync when I log in ticked so it starts by itself. macOS then shows "Background Items Added": that's Interface Sync, and it's fine. You can switch it off any time from the menu-bar icon (Open at Login) or in System Settings → General → Login Items.

After that, Interface Sync lives in the menu bar (top right).

Is this safe?

The app is built in public by GitHub Actions from the project's source code. It reads and writes only your World of Warcraft WTF/Account folder and its own folder in your cloud drive. It never touches the game itself, your addons or Config.wtf.
