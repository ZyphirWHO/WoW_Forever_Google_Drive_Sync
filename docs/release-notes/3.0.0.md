## What's new in 3.0

Interface Sync keeps your World of Warcraft interface settings (keybindings, macros and addon settings) the same on
every computer you play on, through your own Google Drive, OneDrive or Dropbox. It replaces WoWSync 1.1.

- **Windows and Mac.** A tray app on Windows and a menu-bar app on Mac, syncing with each other.
- **Google Drive, OneDrive or Dropbox**, found automatically.
- **Safe by design.** Settings sync only while the game is closed, every change is backed up first, and your game
  files, addons and `Config.wtf` are never touched.
- **Setup in a minute.** A short wizard checks what it found and, if your cloud folder already has settings from
  another computer, asks which ones this computer should use.
- **Restore.** Each game version's **Restore…** button puts your settings back as they were at any backup.
- **"Changed in two places"** shows both copies side by side, so you can choose; the other one is kept as a backup.
- **Light and dark**, with a sun/moon switch at the top of every window.
- **Starts with your computer** if you want it to, and **updates itself**: it checks GitHub once a day.
- **Easy on your SSD.** Nothing is written while idle, and a sync writes only the files that changed.

### Installing

- **Windows:** download `InterfaceSync-Setup-3.0.0.exe` and run it. It installs for you only, with no administrator
  rights needed. Windows may warn that it doesn't recognise the app yet: click **More info**, then **Run anyway**.
- **Mac:** download the `.dmg` for your Mac (`arm64` for Apple silicon, `x64` for Intel) and drag Interface Sync onto
  Applications. The first time you open it, go to System Settings → Privacy & Security and click **Open Anyway**.

Coming from WoWSync 1.1? Stop its agent first; Interface Sync finds your existing cloud settings and carries on.
