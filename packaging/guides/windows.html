Opening Interface Sync on Windows

Interface Sync isn't code-signed yet, so your browser and Windows may warn about it the first time. You only have to do this once. No administrator rights are needed.

1. The browser says it's "not commonly downloaded"

  1. Edge: click … next to the download → Keep → Show more → Keep anyway.
  2. Chrome: in the downloads list, click Keep (or the arrow → Download suspicious file).

2. "Windows protected your PC"

  1. Click More info.
  2. Click Run anyway.
Put InterfaceSync.exe somewhere it will stay, for example a folder in Documents, before running it. Don't run it from inside the zip.

3. First setup

A setup window explains how syncing works. If your cloud folder already has settings from another computer, it asks, for each game version, whether to use the settings already in the cloud or use this PC's settings. The newer one is picked for you; the other copy is backed up either way. Click Start syncing.

After that, Interface Sync sits in the system tray (bottom right; click the ^ arrow if you don't see it). Right-click the icon for the status window, backups and settings.

Check the file (optional)

In PowerShell, run Get-FileHash .\InterfaceSync.exe in the folder you saved it to. The SHA-256 must match the one on the download page.

Antivirus warnings

Unsigned new apps sometimes get flagged by reputation alone. See ANTIVIRUS.md on the project page for how to check the file and report a false positive.

Is this safe?

The app is built in public by GitHub Actions from the project's source code. It reads and writes only your World of Warcraft WTF\Account folder and its own folder in your cloud drive. It never touches the game itself, your addons or Config.wtf.
